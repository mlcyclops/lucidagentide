## Why leadership says yes

<table>

## New in v2.7: Agents you can see, schedule and keep light

**The short version for leadership.** One person can now keep several AI agents working side by side and see at a glance which ones are busy. Routine work, such as a nightly test run or a weekly report, can be scheduled to run on its own. LUCID itself now uses a small fraction of the computer it used before. Every agent still sits behind the same security gate, and that gate cannot fail open.

| What changed | Why it matters |
| :-- | :-- |
| **Agents on the right rail**: each project folder is a small Lucid that lights up while it works | You see who is working and who is idle without opening anything |
| **Schedule this Agent**: once, daily, weekdays, chosen days or monthly, with a goal in plain words | Routine work runs on time without anyone starting it |
| **Floating Agents** suggest the next step, ready to run in parallel or to ask about | Less time deciding what to do next, more work in parallel |
| **Ask Lucid** shows what it is doing while you wait, and answers with Claude Haiku 5.5 | Quick answers about your work without stopping the main agent |
| **Lighter and steadier**: an idle LUCID went from about 25% of the CPU to about 1%, and no git runs at startup | Laptops stay quiet, and the window keeps up with many agents at once |

## New in v2.6: Lucid Agent Worlds

<div align="center">
<img src="docs/images/worlds/worlds-hero.webp" alt="Four Lucid Agent Worlds in Visualize: Christmas, Basketball with an approval pop-out, Soccer with a sandboxed sample game, and Football" width="100%" />

Visualize draws your AI agents as characters and their work as streams of light. A world turns that scene into a themed setting, so a team of agents reads like a game you can follow at a glance.

- **40 worlds**, from Christmas and Football to Hospital, Grand Prix, a carrier flight deck, Orbital Ops and Florida, each with a mixed cast whose skin and hair you choose.
- **Approve tool calls inside Visualize**: a badge appears over the agent that is asking, with Approve, Auto and Deny.
- **Sample games** in every world open only after LUCID's security check, with no internet and no access to LUCID.
- **Get them** one at a time or as a bundle at the **[LUCID store](https://store.lucid-agents.com)**, then install from **Preview > Plugins > Premium**.

Nothing else to install: every build bundles what it needs and works offline. On macOS, Homebrew installs and updates LUCID with no security prompt:

```bash
brew tap mlcyclops/lucid https://github.com/mlcyclops/lucidagentide
brew trust --cask mlcyclops/lucid/lucidagentide
brew install --cask lucidagentide
```

Updating keeps your settings, sessions and keys. Found a bug? **[Open an issue](https://github.com/mlcyclops/lucidagentide/issues/new?template=bug_report.yml)**; [Support](docs/SUPPORT.md) explains how to attach logs.

<details>
<summary><b>For developers: run from source</b></summary>

<br/>

LUCID is a security, provenance and memory layer built around [oh-my-pi](https://omp.sh) through its hooks, custom tools and SDK, never a fork. The harness is TypeScript on Bun; the only Python is the Unicode scanner sidecar.

```bash
bun install                       # harness deps (Bun >= 1.3)
cd scanner-sidecar && uv sync     # pinned Python sidecar venv
make test                         # full suite: harness + desktop + scanner sidecar
bun run demo-00                   # omp round-trip + scanner + fail-closed proof
```

Requires [Bun](https://bun.sh) and [uv](https://docs.astral.sh/uv/). Every increment ships with an ADR, tests and a runnable `make demo-<id>`.
