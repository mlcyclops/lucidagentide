1Do this in LUCID right now

The short version

Two independent doors. The Connect via OAuth button on the OpenAI card signs in your ChatGPT/Codex subscription and surfaces the models that plan covers. Pasting an OPENAI_API_KEY instead unlocks the full commercial catalog, billed per token. For coding agents, the sweet spot is Pro Codex at $100/mo; for a first taste, Plus at $20 or a pay-as-you-go key.

Path A: subscription OAuth

In Settings > Providers > OpenAI · ChatGPT, click Connect via OAuth and sign in with the account that holds your ChatGPT plan. LUCID then shows the models your subscription entitles you to, the same set the Codex CLI would see. Usage draws down your plan's limits, not a separate API bill.

Path B: API key, full catalog

Create a key at platform.openai.com, paste it into the OPENAI_API_KEY box on the same card, and Save. Every commercially available OpenAI model appears in the picker, including ones your ChatGPT tier does not include. Billing is per token against your platform account. Both paths can coexist; the picker labels which door each model came through.

3Model history: GPT-5 to GPT-6 Astra

Thirteen months, six releases. The pattern: a flagship, then coding and reasoning specialists, then a family split by speed and cost, then the next flagship at a higher price.

Aug 2025

GPT-5 launches, posting 74.9% on SWE-bench Verified at release. The baseline the whole 5.x line iterates on.

Feb 5, 2026

GPT-5.3-Codex: a coding agent specialist tuned for the Codex CLI and long tool-use sessions rather than chat.

Mar 5, 2026

GPT-5.4: tops Scale's standardized SWE-bench Pro public set at 59.1% (xHigh effort). Still the vendor's best score on that harness as of September 2026.

Apr 23, 2026

GPT-5.5: built for long-horizon agentic work. Its Pro variant is the headline model of the $100 Pro Codex tier.

Jul 9, 2026

GPT-5.6 family: three models, three jobs. Sol for reasoning at $4/$20 per 1M tokens, Terra balanced, Luna fast and cheap.

Sep 3, 2026

GPT-6 Astra: 1M-token context, API pricing $10 in / $50 out per 1M with cached input at $1, roughly 2.5x the GPT-5.6 Sol price. The launch version is restricted on some cybersecurity prompts, so security tooling workflows should test before committing.

4Benchmarks, honestly

Two leaderboards, two very different numbers

SWE-bench Verified figures (like GPT-5's 74.9% at launch) are largely self-reported by vendors, each running their own scaffolding. Scale's standardized SWE-bench Pro harness runs the same setup for everyone and scores every vendor much lower; on its public set, GPT-5.4 leads at 59.1%. Compare models within one harness, never across the two, and treat vendor launch numbers as marketing until a standardized run confirms them.

The LUCID rule of thumb

Subscription OAuth when your usage is steady and fits one tier's limits; API key when it is spiky, when you need a model your tier lacks, or when you want one bill across several tools.
