1Do this in LUCID right now

The short version

Two clean paths, no gotchas. Connect via OAuth signs in your Claude subscription (Pro, Max, or Team) and bills against its usage caps. Pasting an ANTHROPIC_API_KEY is pure pay-as-you-go per token. Either way, a fresh LUCID lands on Opus 5: it is the house default model, so the moment the card is connected you are on Anthropic's flagship.

Path A: subscription OAuth (Pro, Max, Team)

If you already pay for Claude, use it. In LUCID: Settings > Providers > Anthropic · Claude, click Connect via OAuth, and sign in with the account that holds the plan. Claude Code access is included on Pro and up, and LUCID rides the same entitlement. Your subscription's usage caps apply; a Max plan raises them 5x or 20x over Pro.

Path B: API key, pay per token

Create a key in the Anthropic console and paste it into the ANTHROPIC_API_KEY box on the same card, then Save. No subscription needed: you get the commercial catalog billed per million tokens at the rates in section 5. Best for spiky or light usage, worst for a heavy daily driver (section 6 has the crossover math).

3The $13/dev/day seat math

Anthropic's own docs put average Claude Code spend at $13 per developer per active day when billed through the API. That one number is the whole purchasing decision:

  • At roughly 20 active days a month, an average Claude Code developer burns about $260/mo in API terms (approximate, derived from the $13 figure).
  • Max 5x at $100 is therefore cheaper than API billing for anyone using Claude Code most working days, and Max 20x at $200 still undercuts the average heavy month.
  • For a team, a $25 standard seat covers light users and a $125 premium seat covers the daily agent drivers; mixing seat types usually beats putting everyone on API keys.

Rule of thumb

Fewer than about 8 active Claude Code days a month: stay on the API key. More than that: a subscription wins, and the only question left is which cap you keep hitting.

Read the benchmarks honestly

SWE-bench Verified numbers are largely self-reported by vendors under their own harnesses; standardized SWE-bench Pro runs score every vendor much lower. That is why Fable 5 can post 95.0% on Verified while Fable 5.1 leads the standardized board at 81.2%. Compare models within one board, never across the two.

The Fable exception

Fable 5 is billed as premium API credits at $10/$50 per 1M regardless of subscription, so a Max plan does not make it free. Keep Opus 5 (the LUCID default) as the daily driver and reach for Fable deliberately, on hard problems worth the premium.
