1Do this in LUCID right now

The short version

If you want something working in five minutes for free, paste a Gemini AI Studio key into the Gemini card (section 3, rung 1). If you already know your workload, jump to the table in section 2 and connect the one or two cards it names. If you would rather be walked through it, type /providers in the chat plus a sentence about what you are trying to do, and the agent runs this selection interactively (section 5).

One onboarding fact worth knowing: a fresh LUCID points its model picker at Claude Opus 5, Anthropic's flagship and the house default. That model only answers once the Anthropic card is connected (OAuth sign-in for a Claude subscription, or an ANTHROPIC_API_KEY). If you have neither and do not want to pay yet, start the free ladder in section 3 and pick any connected model from the picker instead.

Everything below happens in Settings > Providers. Each card offers one or both of: a Connect via OAuth button (sign in with the subscription you already pay for) and an API key box (pay per token). Subscriptions give you a flat bill; keys give you the full catalog and metered cost.

Reading coding benchmarks honestly

Vendors advertise SWE-bench Verified scores that are largely self-reported and cluster in the high 80s to mid 90s. Scale's standardized SWE-bench Pro harness scores every vendor much lower and reshuffles the order. Treat headline numbers as relative hints, not absolutes, and check the per-provider guides for the current figures on both boards before betting a workflow on one model.

Regulated work and the gated providers

The OTHERS section of Settings (DeepSeek, Qwen, Kimi, GLM, MiniMax, Groq, OpenRouter) sits behind a typed ACKNOWLEDGE because those routes reach non-U.S. servers or aggregate many origins with no U.S. data-sovereignty guarantee. For defense or regulated-adjacent work, treat them as off-limits and stay on the AskSage or Azure paths.

3The free start ladder

Zero to near-zero cost, in the order to try them. Each rung is real, not a trial that dies in a week.

Rung 1 · $0, five minutes

Gemini AI Studio key. The fastest zero-cost start in the app: get a key at aistudio.google.com/apikey with any Google account and paste it into the Gemini card's GEMINI_API_KEY box. Full model catalog, daily rate limits, no card on file.

Rung 2 · $0, limited

GitHub Copilot Free. Limited completions and chat, but a real multi-vendor tier. Click Connect on the Copilot card and paste the device code on the GitHub page it opens.

Rung 3 · $0, privacy tradeoff

xAI's data-sharing credit program. Up to $175/month in free API credits in exchange for sharing your usage data. Read the privacy terms before opting in: you are paying with your prompts. Connect the xAI card via OAuth or an XAI_API_KEY.

Rung 4 · pennies per session

The ACKNOWLEDGE-gated APIs. DeepSeek, MiniMax, and Groq charge fractions of a dollar per million tokens (DeepSeek V4 Flash from $0.22 in, MiniMax M3 at $0.30/$1.20, Groq from $0.05). Type ACKNOWLEDGE in Settings to reveal the cards, then paste the vendor key. Mind the data-sovereignty caveat from section 2.

Rung 5 · one key, many models

OpenRouter free variants. One aggregator key exposes many models including free variants, and the card supports OAuth. A U.S. company, but requests route to many origins; it lives behind the same ACKNOWLEDGE gate.

The ladder is also an upgrade path

Nothing here locks you in. Most people start on rung 1, discover which workload actually consumes tokens, and only then buy the one subscription from section 2 that matches it.

4Creative media: the Creator Edition

LUCID Creator Edition

Creative media work gets its own release build. The Creator Edition adds TTS and voice cloning, music generation, ComfyUI image and video pipelines, three.js scenes, Blender renders, Unreal builds, and a follow-along audio editor on top of everything in the standard app. Download the latest Creator artifact for your OS from github.com/mlcyclops/lucidagentide/releases. On macOS the standard build also installs via the Homebrew cask lucidagentide.

TTS + voice cloning Music generation ComfyUI image/video three.js scenes Blender renders Unreal builds Follow-along audio editor

One key works everywhere: an ElevenLabs key powers voice features in any build, Creator or standard. Paste it into Settings > Voice. Image and video models plug in through their own provider cards as usual, so a creative setup is typically Creator Edition + ElevenLabs + one image-capable provider from section 2.

5Going deeper: guides, toasts, /providers

Let the agent run the selection

Type /providers in the chat followed by what you are trying to do, for example /providers heavy agentic coding, budget $100. The agent reads these advisor guides, verifies current pricing on the live web, and walks the selection with you interactively: it asks about your workload, compares the plans that fit, and points at the exact Settings fields to fill.

Every card carries its own deep dive

This page is deliberately shallow. Every provider card in Settings > Providers links its own guide: plan tables, model release history, benchmark caveats, and the exact wiring (OAuth scope, key names, extra fields like Azure resource names or GCP project IDs) for that vendor.

Failed sign-ins explain themselves

When an OAuth connect fails, LUCID surfaces the real reason as a red toast and a note on the card, for example a subscription tier that does not include IDE access. You never have to guess whether the button worked; if something is missing, the card says what.
