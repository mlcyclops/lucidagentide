1Do this in LUCID right now

The short version

Click Connect via OAuth on the xAI card and sign in with your X / xAI account: whatever your plan entitles you to shows up in the model picker. No subscription, or want pay-per-token instead? Create a key at console.x.ai and paste it into the XAI_API_KEY box. If a Grok model returns empty replies, that is not a bug in LUCID: your plan does not cover that model.

Path A: subscription OAuth

In Settings > Providers > xAI · Grok, click Connect via OAuth and sign in with the X or xAI account that carries your subscription. The catalog you see afterward is plan-gated: a SuperGrok subscriber sees more than an X Premium subscriber, and SuperGrok Heavy unlocks new flagships first. If a model you expected is missing, the plan is the reason, not the connection.

Path B: API key, pay per token

Create an API key at console.x.ai, paste it into the XAI_API_KEY field on the xAI card, and Save. This bills per token at the API prices in section 3 and is independent of any grok.com or X subscription.

Empty replies are a plan gap, not an outage

When a Grok model streams back nothing at all, xAI accepted the request but your entitlement does not include that model. Check your plan and key status at console.x.ai before filing it as a LUCID bug.

Which path for a small business?

If Grok is a research sidekick, SuperGrok at $30/mo is the sweet spot: DeepSearch plus real-time X data is the thing no other provider bundles. If it drives agents in LUCID all day, skip subscriptions and use the API key; the per-token prices below are competitive. Buy X Premium+ only if you also want ad-free X: as a Grok plan alone, $40 buys less than SuperGrok's $30.

3Grok 4.6 and Grok Build API pricing

Grok 4.6 (released Aug 12, 2026) is xAI's long-horizon model: a 500K-token context window, built for long-running agents, coding, and research sessions. Grok Build 0.1 is the cheap coding specialist. API prices per 1M tokens:

The 200K-token price cliff

Grok 4.6's 500K context is real, but crossing 200K tokens in a single request doubles both input and output pricing ($2/$6 becomes $4/$12). Long agent sessions in LUCID accumulate context quickly: keep an eye on context size, and let LUCID's compaction run before a session drifts past the threshold, or the last third of the window costs twice as much as the first two.

The $175/mo "free" credits are paid for with your data

xAI offers up to $175 per month in free API credits through its data-sharing program: in exchange, your API traffic can be used by xAI. Read the privacy terms before opting in. Do not enroll a key that touches client work, proprietary code, or anything you are contractually obliged to keep confidential. For hobby projects and public-data experiments it is genuinely free money.
