Behavior notes
  • The Agent box is the real metric .tile (copied verbatim) at the rail's measured width: 76 x 49 px. The art takes the number's slot (28 px), the name takes the label slot and ellipsizes.
  • Block = an isometric glass cube (frosted faces, bright front edge, glints) on a voxel pedestal in the Agent's color: four lit top voxels, shaded sides, a neon seam. The Lucid sits inside like a figurine in a display case.
  • Idle: meditating, 4.8 s breath, the pedestal glow under him breathes too. Working: typing bursts with a rest on a holo keyboard, keys flash, two code bits rise. LED dot = working.
  • Glance: about every 60 s (jittered), 3.2 s: left, up, down, then center toward the user with one blink. ml-notebooks glances every 6.5 s here only so reviewers can see it.
  • Toggle: the bust sits on an iso-cube hexagon that turns a sixth on hover, like a voxel being rotated.
  • Hover: 140 ms intent, 260 ms grace. The module prefers the left of the box, clamps inside the window, its nub tracks the box. Reduced motion stops every loop; pose and LED still read.
