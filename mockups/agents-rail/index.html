Agents rail · three visual directions

A new Agents view for the right metrics rail: a mini LUCID toggle sits right of the expand button, and each Agent (a recent repo, working folder, or saved Agent) lives in a metric-sized box as a mini Lucid sealed in a block. Each page shows the real app proportions, both toggle states and hover, six Agents in different colors and states, the hover module with Activate expanded, and a first-run variant. Previews below are live; open a card for the full page.

Direction A
Glass brick

The Brick Brigade brick, made translucent in the Agent's color: bevel, recessed window, gloss band, glass streaks, troop trim. A smooth vector chibi Lucid inside.
Direction B
Pixel brick

The real 20 x 26 mascot grid from mascot.ts at 1 px per cell, sealed in a pixel-art brick. Frame-swap animation only, so it stays crisp at 1x, 2x and 4x.
Direction C
Voxel cube

An isometric glass cube on a voxel pedestal in the Agent's color, the Lucid inside like a figurine in a display case. The toggle's hexagon turns like a voxel.
